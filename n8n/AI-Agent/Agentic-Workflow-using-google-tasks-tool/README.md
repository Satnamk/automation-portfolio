# AI Agent Workflows

## Overview
This folder contains AI Agent–based automation workflows built using **n8n** and **OpenAI**.

These workflows demonstrate how AI models can be integrated into automation pipelines to make decisions, analyze data, and perform intelligent actions with minimal human intervention.

---

## What is an AI Agent?
An AI Agent is an automated system that uses artificial intelligence to:
- Understand inputs
- Make decisions
- Generate responses
- Trigger actions across multiple systems

In n8n, AI agents are created by combining AI models with workflow logic, APIs, and external tools.

---

This folder contains an agentic workflow that integrates AI with Google Tasks using n8n.
