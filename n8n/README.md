# n8n Email Notification Workflow

## Description
This workflow sends an email to the user with a custom subject and message.

Sticky notes are used inside the workflow only for documentation and learning purposes, such as storing n8n keyboard shortcuts for the creator’s reference. They are not connected to the automation logic.

---

## Workflow Overview
The workflow performs the following actions:

1. Trigger starts the workflow
2. Email subject and message are defined
3. Email is sent to the specified user

---

## Tools Used
- n8n
- Email (SMTP / Gmail)
- Sticky Notes (internal documentation only)

---

## Purpose
- Learn basic n8n workflow structure
- Practice email automation
- Understand triggers and email nodes
- Use sticky notes for internal documentation

---

## How to Use
1. Import the JSON workflow into n8n
2. Configure email credentials
3. Update recipient email address
4. Edit subject and message if required
5. Activate the workflow

---

## Notes
- Sticky notes are for creator reference only
- They do not affect workflow execution
- No credentials or API keys are included
